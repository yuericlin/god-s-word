# God's Word Library

A SWORD module repository for the **God's Word** iPhone Bible reader.

The modules here are public-domain works converted from other
module formats (such as e-Sword) into standard SWORD packages,
so the app can offer them like any other repository source.

## Modules

- **DarbySynopsis** — *Synopsis of the Books of the Bible* by
  John Nelson Darby (1800–1882). Chapter essays for all 1,189
  chapters, converted from the public-domain text of the
  Synopsis (1857–62).

## Layout

Standard CrossWire raw-repository layout: `mods.d.tar.gz`
catalog, one `.conf` per module under `mods.d/`, and module
packages under `packages/`.
